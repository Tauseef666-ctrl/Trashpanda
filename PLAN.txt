The 10 rules of TrashPanda (safety first, always)
  1. Scan reads ONLY. Deletion is a separate, explicit action.
  2. Nothing is ever hard-deleted. Recycle Bin / undo folder only.
  3. Risk chips: GREEN auto-check ok, AMBER user must tick, RED show only.
  4. Locked/in-use files are skipped silently, never killed.
  5. Junctions/symlinks are never followed (no loops, no surprise dirs).
  6. Every attack shows the exact path + size BEFORE deletion.
  7. A receipt is saved after every clean (before/after + file list).
  8. No registry cleaner. No driver updater. No antivirus upsells. Ever.
  9. No network calls in v0/v1. 100% local. No telemetry.
  10. User data (Documents, project code, session DBs) = ALWAYS ask-first.
